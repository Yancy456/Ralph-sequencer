## Template_demo

The Ralph-sequencer provides following templates to guide user through the project:
you should ask user to use which template to use.
- disk_analysis: A template to provide a detailed analysis of the disk.
- long_novel_writer: A template to guide user through the process of writing a long novel.

## Tell the user to how to create template

1. Once you have comfirm the user to use the template, you should tell the user to run following command to create the template:
```
ralph-sq template <template_name>
```
2. Run command the exit the terminal
```
ralph-sq exit
```
